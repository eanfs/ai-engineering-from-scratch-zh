在提示词后面加五个字：让我们一步步思考。
准确率从百分之七十八涨到百分之九十一。
同一个模型、同样的温度、同样的 API 成本。
阶段 11，第 2 课：少样本提示、思维链与思维树。
告诉模型该做什么，那是提示。
教它该怎么想，那是工程。
给模型一个任务不给例子，叫零样本。先给几个例子，叫少样本。
简单任务上，两者差不到两个百分点。
但多步算术和符号推理，少样本能提十到二十五个点。
与其描述输出格式，不如直接展示格式。
与其解释推理过程，不如直接演示一遍。
模型在示例上做模式匹配，比解读抽象指令可靠得多。
不是随便挑几个例子就行。
三条原则：语义上离目标输入近、覆盖所有输出类别、难度匹配。
最优数量是三到五个，少于三个信号不够，多于五个收益递减。
标准提示下，模型要把所有推理压进一次前向传播的隐藏状态里。
思维链让它把中间计算写成 token。
每个推理 token 都成为下一个 token 的上下文，等于延展了计算深度。
小学数学基准 GSM8K，八千五百道题。
GPT-4o：零样本七十八，加思维链九十一，再加少样本九十五。
GPT-5 从九十四到九十七再到九十八，Llama 4 70B 从八十到八十九再到九十四。
o3、o4-mini、DeepSeek R1 这类推理模型，内部已经跑过思维链。
再给它们加「让我们一步步思考」是多余的。
有时甚至帮倒忙，因为它们已经做过这件事了。
单条推理路径可能出错，那就采样五条。
对最终答案做多数表决，错误会相互抵消。
实测五条路径里，四条算出 24，一条算出 27，最终答案是 24。
自洽性是采样多条独立路径，思维树是把路径展开成一棵树。
每一层生成几个候选想法，评估打分，剪掉差的分支。
它更像人在草稿纸上涂改，而不是一口气写到底。
简单事实回忆、单步分类，思维链是浪费。
每次查询会多出五十到两百个 token 的推理开销。
高吞吐、低复杂度的任务上，那就是白花的成本。
你的场景里，加思维链是赚还是亏？
