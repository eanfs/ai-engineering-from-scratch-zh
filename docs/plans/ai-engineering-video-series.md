# 用 Hypit 制作 AI 应用与 Agent 中文短视频系列

## 制作目标

首批制作 **12 集、每集 1–3 分钟、16:9 横屏、1080p** 的知识短视频，采用中文云端旁白、动态图解和代码演示。先完成 3 集样片，验收后制作其余 9 集。

课程素材来自本仓库。面向具备基础编程能力、希望理解 AI 应用与 Agent 的观众。每集讲清一个机制，并引导观众阅读原课、运行实验；不将完整课程压缩成逐字朗读。

## 制作流程与 Hypit 实现

- **建立独立制作工程：** 默认放在课程仓库的同级目录 `ai-engineering-from-scratch-zh-videos`，使用 [Hypit](https://github.com/hypit-ai/hypit) 作为制作工具。视频制作时课程仓库只读，视频工程保存脚本、素材、制作源文件和结果。
- **提取课程依据：** 从中文讲义、代码、测验和术语表整理每集学习目标、关键结论、演示方法及来源。记录课程 Git 提交，便于后续更新追踪。
- **改编视频脚本：** 每集默认约 120 秒、350–500 字，按“问题 → 机制 → 示例 → 边界 → 原课练习”组织。实际时长以配音测量结果为准，超过 3 分钟时删减内容。
- **统一视觉模板：** 制作标题卡、机制图、代码高亮、运行结果和总结卡五类可复用组件。代码每屏以 5–10 行为主；公式、标识符保持准确，字幕避免遮挡演示区域。
- **区分图解与证据：** 概念关系用可编辑动画；声称代码运行成功时展示真实执行结果。需要外部模型的演示采用明确标注的确定性模拟，首批不新增课程模型调用费用。
- **配音与时间编排：** 在现有 Hypit Provider 能力范围内选择支持中文的云端 TTS，先验证术语样句、报价和账户连接，再固定音色。用配音对齐字幕及语义事件，驱动图解与代码变化。
- **验证和导出：** 使用 SVML 编排、Recipe 生成素材、SVRun 选择生成或复用结果；依次执行 `check`、`plan`、`build`。通过 Studio 检视，并观看、听审最终 MP4。

每集交付 MP4、SRT 字幕、封面、发布文案、课程链接和可编辑制作源文件。系列另交付选题清单与进度表；不新增 Hypit 核心公共 API。

## 分批安排与验收

1. **准备批：** 完成 12 集内容提纲、统一模板、术语发音表及云端试音。
2. **样片批：** 完成第 02、07、09 集，确认讲解深度、声音、代码可读性和视觉节奏。
3. **量产批：** 根据样片反馈调整模板，将剩余 9 集分成三个批次制作；最终按 01–12 排序交付。

验收要求：

- 每集 60–180 秒，输出 1920×1080；字幕与音画同步，无截字、遮挡或明显音频问题。
- 技术结论可追溯到课程来源；删减后仍保留必要前提，模拟结果有明确标注。
- 代码演示运行对应检查，结果与画面一致；字幕和旁白准确读出关键术语。
- 修改旁白后，关联动画能随语义位置调整；重建时可复用未变素材，失败后不重复生成已完成配音。
- 样片与每批最终视频均完整观看、听审，再交付。

## 默认条件与费用边界

- 首批仅覆盖上述 AI 应用与 Agent 主题；基础数学、模型训练及认证课程留待后续系列。
- 云端配音总预算上限 **¥100**，包含试音与重做。此金额是预算约束，不是成本预测。
- 具体 TTS 服务在准备批按可用 Provider、实时报价和试音结果确定；费用超限时暂停新增付费请求，由用户决定调整。
- 当前尚未确认 Hypit 可执行环境和云端账户可用性，环境检查是制作开始前的必要步骤。
- 首批不使用数字人或生成视频素材。发布平台暂不绑定，交付通用横屏文件与文案，不自动上传。
